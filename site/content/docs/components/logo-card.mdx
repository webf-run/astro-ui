`BrandLogoCard` displays a brand logo in a polished, accessible tile. Add `href` to make the card a link, or omit it when the logo is decorative.

## Basic Usage

The `LogoCard` component displays a company, client, partner, or sponsor logo along with its name. Provide the logo source using an image URL and optionally pass an `href` to make the card clickable. This example demonstrates using external image URLs for different logo sources.

## Props

| Prop          | Type                                                 | Description                                                                                   |
| ------------- | ---------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| `logo`        | `string`                                             | Image URL for the brand logo.                                                                 |
| `companyName` | `string`                                             | Brand name used for accessible text and image alt attributes.                                 |
| `href`        | `string`                                             | Optional URL that makes the logo card clickable.                                              |
| `target`      | `'_blank' \| '_self'`                                | Link target behavior. Defaults to `'_blank'`.                                                 |
| `size`        | `'sm' \| 'md' \| 'lg'`                               | Controls the card dimensions. Defaults to `'md'`.                                             |
| `variant`     | `'default' \| 'blue' \| 'green' \| 'gold' \| 'dark'` | Applies predefined background and border color themes. Defaults to `'default'`.               |
| `class`       | `string`                                             | Additional CSS utility classes for custom styling.                                            |
| `style`       | `string`                                             | Inline CSS overrides for advanced customization such as shadows, borders, or special effects. |

## Default Behavior

The `LogoCard` component provides built-in sizing and color variants while allowing further customization through the `class` and `style` props.

- Use `size` to control predefined card dimensions.
- Use `variant` to apply consistent theme styles.
- Use `style` for one-off customizations such as shadows, gradients, or additional visual effects.
- Use `class` when extending the component with utility classes.
