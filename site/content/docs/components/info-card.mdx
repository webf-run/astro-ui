`InfoCard` is a reusable information display component designed for presenting statistics, metrics, summaries, and quick insights.

It supports multiple color variants, predefined sizes, horizontal and vertical layouts, visual effects, and border customization. This makes it suitable for analytics dashboards, SaaS applications, education platforms, healthcare websites, e-commerce stores, and marketing landing pages.

## Color Variants

Use variants to match different brand identities, categories, or information types.

Supported variants:

- `purple` — General purpose, education, premium sections
- `blue` — Technology, business, analytics
- `green` — Growth, success, finance
- `orange` — Products, warnings, highlights
- `red` — Alerts, critical information
- `neutral` — Minimal and clean interfaces

<CodePlayground code={variantsCode} />

## Sizes

Choose the appropriate size based on the placement and importance of the information.

- `sm` — Compact layouts, side panels, small widgets
- `md` — Default size for dashboards and content sections
- `lg` — Featured statistics and promotional sections

<CodePlayground code={sizesCode} />

## Layouts

Change the card arrangement using horizontal or vertical layouts.

### Horizontal Layout

The default layout places the icon and content side by side, making it suitable for dashboards and data summaries.

### Vertical Layout

The vertical layout centers the icon and content, making it ideal for landing pages, feature sections, and highlight cards.

<CodePlayground code={layoutsCode} />

## Visual Effects

Add depth and emphasis using built-in effects.

Available effects:

- `none` — Default flat appearance
- `shadow` — Adds subtle elevation
- `lift` — Adds hover movement and stronger elevation
- `glow` — Creates a colored highlight effect
- `gradient` — Applies a soft gradient background

<CodePlayground code={effectsCode} />

## Border Customization

Set `bordered={false}` to drop the border for minimal designs or when placing a card on an already styled background — see the last card (`Downloads`) in the [Visual Effects](#visual-effects) example above.
