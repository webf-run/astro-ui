The `Navbar` component provides a responsive navigation bar for Astro applications. It supports branding through a logo, configurable navigation links, optional dropdown indicators, and customizable link styles. A built-in call-to-action button makes it ideal for marketing websites, documentation portals, and educational platforms.

Use the interactive playgrounds below to experiment with different navbar configurations and see the output update in real time.

## Basic Navbar

Create a responsive navigation bar by providing a logo and a list of navigation items. The component automatically renders the navigation links and includes a call-to-action button.

## Dropdown Navigation

Set `hasDropdown` to `true` on any navigation item to display a dropdown indicator. This is useful for menu items that contain additional navigation options.

## Custom Navigation Styles

Use the `class` prop to apply custom Tailwind or CSS utility classes to all navigation links, allowing the navbar to match your brand or application theme.

## Logo Only

The navbar can also be used with only a logo. Navigation links are optional, making it suitable for landing pages, authentication screens, or simple layouts.
